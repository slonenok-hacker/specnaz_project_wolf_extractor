# UFF Extractor for Specnaz: Project Wolf

Набор скриптов для извлечения файлов из архивов формата UFF (`.bfs`) игры *Specnaz: Project Wolf*.  
Проект содержит два отдельных инструмента: один для архивов `main01–03.bfs` (на базе проверенной версии v1), второй — специально для `main04.bfs`, где структура записей отличается.

Репозиторий: [slonenok-hacker/specnaz_project_wolf_extractor](https://github.com/slonenok-hacker/specnaz_project_wolf_extractor)

## Особенности

- **Два отдельных скрипта** вместо универсального: это исключает ошибки маппинга имён между разными форматами.
- **Точное соответствие оригиналу**: для main01–03 используется логика v1 (маппинг через поле `parent`), для main04 — через `cur_idx`.
- **Автоматическая деобфускация**: все файлы извлекаются в чистом виде (алгоритм: `(byte - i) & 0xFF ^ 0x16`).
- **Обработка дубликатов**: если встречаются файлы с одинаковыми именами, к ним добавляется суффикс `_N`.

## Требования

- Python 3.8 или выше.
- Никаких внешних зависимостей — используются только стандартные библиотеки.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/slonenok-hacker/specnaz_project_wolf_extractor.git
cd specnaz_project_wolf_extractor
```

Убедитесь, что у вас установлен Python:

```bash
python --version
# или
python3 --version
```

## Использование

### Для main01.bfs, main02.bfs, main03.bfs

Используйте скрипт `uff_universal.py` (версия v1):

```bash
python uff_universal.py main01.bfs main01
python uff_universal.py main02.bfs main02
python uff_universal.py main03.bfs main03
```

### Для main04.bfs

Используйте отдельный скрипт `uff_extract_main04.py`:

```bash
python uff_extract_main04.py main04.bfs main04
```

**Параметры:**
- `<input.bfs>` — путь к архиву.
- `[output_dir]` — папка для извлечённых файлов (необязательный параметр; по умолчанию: `extracted` для v1, `extracted_main04` для main04).

## Формат архивов

| Архив | Размер записи | Маппинг имени | Ключевое поле |
|-------|---------------|---------------|----------------|
| main01–03 | 16 байт | По индексу из поля `parent` | `parent` (2 байта, смещение 14) |
| main04 | 12 байт | По индексу из поля `cur_idx` | `cur_idx` (1 байт, последний байт записи) |

## Пример вывода

При запуске вы увидите:

- Размер архива и количество найденных файлов.
- Список первых 25 файлов с указанием размера и типа (по сигнатуре: WAV, DDS, PNG, JPEG, OGG, BMP).
- Итоговую статистику: сколько файлов извлечено и сколько ошибок возникло.

Пример строки вывода:

```text
  sound/ambient/forest_01.wav (102400 байт) [WAV]
  textures/ui/button_normal.dds (4096 байт) [DDS]
```
